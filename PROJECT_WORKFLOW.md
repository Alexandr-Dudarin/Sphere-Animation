Все следующие изменения применяются в этой копии. Архивы `SphereVisualLab_WaterRipple_v2/v3` были отдельными копиями для просмотра; они больше не используются как рабочие проекты. Обновления передаются как изменения для основной копии, с проверкой исходной версии и сохранением пользовательских правок.

Из терминала приложения:

```powershell
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

Демо воды: http://127.0.0.1:5174/#water-ripple

Перед передачей обновлений проверять `git status --short` и исходный коммит. После применения проверить локальное демо и сохранить принятые изменения в Git. Не считать перенос, коммит или push выполненными без подтверждения команды или пользователя.
